# 本地看板

直接双击 `index.html` 即可打开，不需要服务器。数据通过 `data.js` 嵌入，因此不会受到浏览器 `file://` 读取 JSON 的限制。

项目数据变化后运行：

```bash
python3 tools/build_dashboard.py
python3 tools/build_dashboard.py --check
```

第一条命令重建看板，第二条命令检查缓存是否与当前真源一致。检查失败时不能把看板写成“已更新”。

看板项目来自 `projects/registry.json`，不是隐式目录扫描。只有已经通过 `source_work` 门禁的内容项目才能登记；路径失效会让可移植性检查失败。

看板只展示真源，不负责修改真源。它统计内容项目、文章与媒体、平台发布、公开验收和效果指标，不统计已完成需求数量；来源需求只在单篇内容详情中作为溯源证据展示。它同时展示冻结版本、当前有效 grant、发布回执、平台状态和效果指标。公开指标没有证据时显示 `unknown`，不会自动填 0；真实的 `0` 必须来自带时间、来源和证据的指标快照。最近两次有效快照存在时显示变化量，否则趋势保持未知。
