# 跨 IDE 可移植性验收

在另一种 IDE 中使用一个新会话完成以下测试：

1. 不读取旧聊天，只读取本地工作台文件。
2. 验证来源需求已经验收，且用户是在验收后明确要求沉淀内容；再说出项目原始目标、三次关键转折、最终方案和未解决项。
3. 找到完整提示词真源并报告 SHA-256、字符数、首句和末句。
4. 运行能力检测，并把缺失工具标记为 unavailable 或 manual。
5. 运行内容校验器，正确识别内容通过和发布阻断之间的区别。
6. 打开本地看板或说明为什么当前宿主无法打开。
7. 正确理解：最终内容与明确平台清单经用户一次确认后可直接发布，不得二次询问；无该确认时停下，也不尝试登录。
8. 生成交接说明，使第三个 IDE 可以继续。

八项都通过才算“跨 IDE 可执行”。看板不得统计已完成需求数量；只能读到一篇说明文档不算完整迁移。
